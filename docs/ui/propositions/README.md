# Propositions d'interface (avant code)

Maquettes composées en HTML/CSS (`src/ui.html`, rendu Chrome par `src/render.py`, planches par `src/boards.py`) sur de vraies captures v7 sans interface (`src/bg.py` : rue de La Pompe, intérieur du Passage, mobile 390x844). Aucun texte généré par IA, aucune modification du jeu.

- `direction-A.png` : radio de récupération (ambre)
- `direction-B.png` : carnet de route (papier, encre)
- `direction-C.png` : diégétique minimal (transparent)
- `comparatif.png`

Chaque planche montre : HUD d'exploration (PV, $, quartier, Nilo, accès Sac / Journal / Carte), dialogue avec choix en bas à gauche, sac et troc (Anselme), option « interface minimale » (touche H), et la version mobile (dialogue, sac).
